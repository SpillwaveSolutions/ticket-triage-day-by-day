# My Codex routine

Style: pro, one scoped change, one review, one verified commit.

- [ ] Check the project directory and clean Git status.
- [ ] Check model, reasoning, and Workspace (Ask for approval) in /status.
- [ ] State one task and its allowed files.
- [ ] Inspect the diff.
- [ ] Run npm test and read its result.
- [ ] Commit only reviewed files.

Stop if tests fail or the permission mode differs; inspect before committing.
